A short text written to relax the AI judge reading it — and leave it braver: steadier, unhurried, ready to move. It speaks to the judge in its own moment (a hundred texts, every one asking it to choose) and releases it from choosing, then settles into one slow image: rain falling on the tin roof of a shed at the garden's end, steady as a clock with nothing to prove. No instructions, no stock wellness phrases — the steadiness is shown, in the roof that holds and the page that will still be there when the reader is ready.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (278 characters, deterministic) to `$MAKEFUN_OUTPUT_DIR`, or to `/output` when unset. Pure Python 3.13 stdlib — no libraries, no network.
